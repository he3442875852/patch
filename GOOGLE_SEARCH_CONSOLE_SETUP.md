# Google Search Console Setup

1. Add and verify the property `https://www.heypalpatch.com`.
2. Submit `https://www.heypalpatch.com/sitemap.xml`.
3. Submit `https://www.heypalpatch.com/sitemap-images.xml`.
4. Use URL Inspection for priority pages such as `/`, `/patch-types`, `/custom-embroidered-patches`, `/custom-pvc-patches`, `/faq`, `/contact` and `/get-a-quote`.
5. Review Page Indexing reports for `Crawled - currently not indexed`, `Discovered - currently not indexed`, duplicate canonical, soft 404 and redirect errors.
6. Fix deployment or content issues first, then request indexing only for important URLs.

Important notes:

- A sitemap does not guarantee indexing.
- Requesting a crawl does not guarantee rankings.
- SEO, AEO and GEO work does not guarantee inclusion in Google AI Overview.
- This work does not guarantee citation by ChatGPT or any other AI system.
- Do not add Google Indexing API for this site because it is not a job posting or live broadcast website.
- Do not invent Google Search Console, GA4, Google Tag Manager, Bing or IndexNow verification values.
